# 멀티페이지 전환 + UI/UX 개선 설계 (v1)

작성 2026-07-24. 리서치(3축 병렬) → 설계. 스택 유지: FastAPI + 단일 vanilla `static/index.html`(빌드 스텝 없음) + Cytoscape.

## 평가자 (누가 "좋다"를 판정하나)
- **1차**: 나(신입 연구자 페르소나). 데모에서 학습 흐름이 매끄럽고 길을 안 잃는가.
- **2차**: 김근태 커피챗 청중(EM 분석가). 프로 수준으로 보이는가.
- **"좋다"의 조작적 정의**: (1) 5개 뷰 라우팅이 브라우저 Back까지 정상, (2) 접근성 체크리스트 PASS, (3) 기존 기능 무손실(회귀 0), (4) 학습루프 3종 동작.

## 아키텍처 결정 (확정)
- **단일 셸 + 클라이언트 라우팅**. 진짜 서버 MPA는 라이브 그래프·SSE를 리로드로 파괴 → 채택 안 함.
- 셸(항상 마운트, 뷰 전환에도 살아있음): 네비 + Cytoscape 인스턴스 + 채팅 스트림 DOM.
- `#main` 영역만 라우팅으로 스왑. 라우팅 = History API + `hashchange`/`popstate` (프레임워크 없음).
- **안정 URL**: `/#/chat`, `/#/chat/{conversation_id}`, `/#/graph`, `/#/graph?concept=X`, `/#/library`, `/#/quiz`, `/#/history`, `/#/settings`. hash 라우팅이면 FastAPI 라우트 추가 불필요(index.html 하나가 다 받음).

## 정보구조 (IA) — 5개 목적지 + Settings
NotebookLM식 3영역(소스│대화│학습 산출물) 정신을 라우팅 뷰로 편다.

| 뷰 | URL | 목적 | 기존 기능 매핑 |
|---|---|---|---|
| Chat | `/#/chat`, `/#/chat/{id}` | 스트리밍 답변+인용, 학습의 중심 | 채팅·인용·노트저장·추천칩 |
| Graph | `/#/graph`, `?concept=X` | 성장 개념지도, 노드→채팅 연동 | Cytoscape 그래프·숙련도 색칠 |
| Library | `/#/library` | 브라우즈/관리 | 숙련도 목록·next_up·노트 목록/내보내기·PDF 업로드 |
| Quiz | `/#/quiz` | 집중 복습 세션(한 문항씩) | 간격반복 퀴즈·서버채점 |
| History | `/#/history` | 대화 목록, 각 항목→`/#/chat/{id}` | 대화기록 재개/삭제 |
| Settings | `/#/settings` | 계정·닉네임·내보내기 | 계정칩 모달 → 뷰로 |

- 네비: 데스크톱 좌측 슬림 사이드바(아이콘+라벨), 모바일 하단 탭바(≤5). Settings는 사이드바 하단.
- **접기 원칙**: 노트·숙련도·업로드는 별도 목적지 만들지 말고 Library/Chat 안으로. 최상위 6개 초과 금지.

## v1 학습루프 신기능 (3종)
1. **하이라이트→설명 (난이도 토글)**: 봇 답변/인용 패널 텍스트를 드래그 선택 → 뜨는 "쉽게 설명" 버튼 → 선택 문장을 초보/전문가 난이도로 재설명 요청(`/chat`에 컨텍스트 주입). EM 전문용어(수차보정·HAADF·cryo-EM) 진입장벽 완화 — 타깃과 정확히 일치.
2. **citation 클릭→원문 점프**: 인용 행 클릭 → 우측 패널에 `cited_text` + 논문 제목 + 페이지 표시. `llm.py`가 이미 `cited_text/start_page/end_page/title` 스트리밍 중 → **PDF 렌더 불필요, 인용 구절 표시로 v1 충족**. `// ponytail: 렌더된 PDF 스크롤 대신 인용 구절 표시. 실제 PDF 뷰어는 니즈 생기면.`
3. **노드클릭→채팅 연동**: 그래프 노드 클릭 → 사이드 패널(개념 상세: 숙련도·관련) + "이 개념 설명해줘" 버튼 → `/#/chat`으로 딥링크하며 질문 주입. 정적 그래프면 가치 반감 → 연동이 차별점.

## UI/UX 프로 체크리스트 (고쳐야 할 부분, 심각도순)
리서치(c) 종합. 각 항목은 pass/fail 검증 가능. 방금 6건은 단일페이지 기준으로 처리됨 — 멀티페이지 전환 시 전 뷰에 재적용 필요.

**높음 (H)**
- [ ] H1 회색 텍스트 페어 전부 ≥4.5:1 측정(반올림 금지). 순수 #000 위 중간 회색이 최대 침묵 실패 지점.
- [ ] H2 비텍스트 대비 ≥3:1: 고스트 보더·입력 아웃라인·아이콘·그래프 스트로크. `#333` 보더는 1.9:1(무효) → ≥`#5A5A5A`.
- [ ] H3 모든 뷰에 가로 스크롤 없음(320px). 대문자+letter-spacing 넓어 조기 오버플로. 그래프만 2D 예외(pan/zoom).
- [ ] H4 상태를 색/명도만으로 표현 금지 — 활성 네비·선택 답안·정오답·노드 상태는 보더/굵기/아이콘/밑줄 병행. 무채색이라 강제됨.
- [ ] H5 터치 타깃 ≥44px(하한 24×24). 아이콘버튼·다이얼로그 × 확인.

**중간 (M)**
- [ ] M1 ARIA: tabs=`tablist/tab/tabpanel`+Arrow, dialog=`aria-modal`+focus trap+Esc+포커스 복귀, nav=`<nav aria-label>`+`aria-current="page"`.
- [ ] M2 포커스 링: 무채색이라 브랜드색 못 씀 → 근백 2px `:focus-visible` 토큰. `outline:none` 단독 금지.
- [ ] M3 async마다 명시 로딩 상태: 스트림·퀴즈채점·그래프빌드·라우트>1s.
- [ ] M4 `prefers-reduced-motion` 경로(그래프 레이아웃 애니 포함). 전역 `* {animation/transition-duration:.01ms}` 폴백.
- [ ] M5 빈 상태 = 온보딩: 첫 채팅·빈 그래프·기록없음에 설명+다음 액션. 순수 블랙은 빈 화면이 고장처럼 보임.

**낮음 (L)**
- [ ] L1 모션 150–300ms 밴드, 목적 있는 이징.
- [ ] L2 각 뷰 URL 주소화 + Back 정상 + 크롬 일관 배치.
- [ ] L3 토큰화(spacing/type/radius/duration/grey-ramp) 한 곳(CSS 변수). 멀티페이지 드리프트 방지.

## 디자인 토큰 (완화형 — 확정)
브랜드 블랙 캔버스 유지, 본문은 off-white, elevation은 위로 밝아지는 표면.
```
--canvas:#000; --surface-1:#0a0a0a; --surface-2:#161616;   /* elevation은 그림자 아닌 명도 */
--on:#ededed;            /* 순백 대신(halation↓) */
--on-mute:#a9a9b2;       /* 9:1, 유지 */
--ink-faint:#8a8a94;     /* 4.6:1, 방금 상향됨 */
--border:#5a5a5f;        /* ≥3:1 (기존 --hairline #3a3a3f는 텍스트 구분선만, 인터랙티브 보더는 --border) */
--focus:#ffffff;         /* focus-visible 링 */
--dur-fast:150ms; --dur-base:200ms; --dur-slow:300ms;
--space: 4/8/12/16/24/32/48;
```

## 채점기 (Step 3, 구현 전 확정)
청크마다 이 게이트를 스스로 돌리고 합격/불합격+근거 보고:
1. 5개 뷰 라우팅: URL 직접입력·네비클릭·브라우저 Back 전부 정상, 새로고침해도 같은 뷰.
2. 접근성: H1~H5 + M1·M2 측정 PASS(브라우저 실측 스크립트).
3. 무손실: 채팅 스트림·퀴즈4/4·노트·재개·업로드·그래프 성장 회귀 0.
4. 학습루프: 하이라이트→설명, citation→구절, 노드→채팅 각 동작.

## 청크 시퀀스 (독립 검증 가능, 한 번에 하나)
구조 먼저(안전·데모 핵심) → 학습루프 뒤에 얹기.
- **C1 라우터+셸**: hash 라우터, 셸에 그래프/스트림 마운트, `#main` 스왑, 5뷰 스텁. 게이트 1.
- **C2 IA 재배치**: 기존 기능을 각 뷰로 이동(Chat/Graph/Library/Quiz/History/Settings). 게이트 3(무손실).
- **C3 네비+토큰+접근성**: 사이드바/하단탭, `aria-current`, 완화형 토큰, H1~H5·M1~M5 전 뷰 적용. 게이트 2.
- **C4 학습루프**: citation→구절, 노드→채팅, 하이라이트→설명. 게이트 4.
- 각 청크: 블래스트 반경 → 최소 변경 → 브라우저 실측 → 내 승인 → (배포 시)커밋.
