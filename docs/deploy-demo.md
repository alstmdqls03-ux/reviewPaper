# 공개 데모 배포

키 없이 도는 MOCK 모드를 올려서, 보는 사람이 clone 없이 클릭만으로 만져보게 한다.

## 무엇이 자동으로 되나

이미지가 빌드될 때 두 가지를 한다.

1. **`python fetch_papers.py`** — 논문 9편(약 55MB)을 arXiv에서 받는다. 저장소에는
   PDF가 없다(재배포 불가 1편·비상업 1편 — `papers/SOURCES.md`). 이걸 빼면
   **소스 0편으로 뜬다.**
2. **쪽 텍스트 사전 추출** — 343쪽, 약 3초. 안 해두면 첫 질문이 PDF 9편을 파싱하는
   동안 멈춰 있고, 무료 티어 콜드 스타트와 겹쳐 "느린 앱"으로 보인다.

포트는 `$PORT`를 따른다. 8000으로 고정하면 PaaS가 헬스체크를 붙이지 못해 배포가 실패한다.

## Render (권장 — 카드 없이 무료)

저장소를 연결하고 **Blueprint**로 배포하면 `render.yaml`대로 뜬다.

```
Render 대시보드 → New → Blueprint → 이 저장소 선택 → Apply
```

`APP_SECRET`·`ADMIN_TOKEN`은 `generateValue: true`라 Render가 임의 값을 만들어 넣는다.
사람이 만들 필요가 없다.

**한계**: 무료 플랜은 15분 무활동이면 잠들고, 다음 요청에서 **콜드 스타트가 30초 이상**
걸린다. 데모 링크를 공유할 때 이 문장을 같이 적는 편이 낫다 —
"첫 로딩이 30초 걸릴 수 있습니다(무료 인스턴스가 잠들어 있어서)."

## Fly.io (대안)

```bash
fly launch --no-deploy --copy-config
fly secrets set APP_SECRET=$(openssl rand -hex 32) ADMIN_TOKEN=$(openssl rand -hex 16)
fly deploy
```

시크릿 2개를 안 넣으면 기동 로그가 이렇게 경고한다 (막지는 않는다).

```
⚠ 외부 공개 전 확인:
   - ADMIN_TOKEN 미설정 → /analytics 가 인증 없이 열려 있음
   - APP_SECRET 기본값 → 계정 토큰을 위조할 수 있음
```

## 공개 데모라서 낮춰 둔 것

아무나 접근하므로 기본값을 그대로 쓰지 않는다. 두 설정 파일에 같은 값이 들어 있다.

| 설정 | 기본 | 데모 | 왜 |
|---|---|---|---|
| `MAX_UPLOAD_MB` | 50 | 10 | 누구나 PDF를 올릴 수 있다 |
| `MAX_SOURCES` | 50 | 3 | 한 사람이 코퍼스를 불릴 수 없게 |
| `RATE_LIMIT` | 30 | 15 | 분당 POST |

무료 티어 디스크는 재시작마다 날아간다. **데모의 대화·노트·숙련도는 영속되지 않는다** —
기능 확인에는 문제없지만, 그게 버그로 보이지 않게 링크에 적어 두는 편이 낫다.

## 실키로 올릴 때

`MOCK_LLM`을 `0`으로 두고 `ANTHROPIC_API_KEY`를 **플랫폼 시크릿으로** 넣는다.
파일에 적지 않는다. 다만 공개 데모에 실키를 붙이면 **모르는 사람의 질문이 내 청구서로
간다.** 논문 9편 전체가 컨텍스트에 들어가면 콜드 질문 1건이 약 $3.70이다
(`docs/roadmap-1y.md`의 비용 공식). 공개 링크에는 MOCK을 권한다.

## 검증되지 않은 것

**이미지 빌드를 실제로 돌려보지 않았다** — 작업 환경에 Docker가 없었다. 빌드 안에서
도는 명령들은 개별로 확인했다.

| 확인한 것 | 방법 |
|---|---|
| `fetch_papers.py` 9/9 다운로드 + sha256 일치 | 신선한 clone에서 실행 |
| 쪽 텍스트 추출 343쪽 / 3.1초 | 캐시를 비우고 계측 |
| `${PORT:-8000}` 치환 | sh로 확인 |

빌드 자체(레이어 순서, 비루트 권한, 헬스체크)는 **첫 배포에서 처음 검증된다.**
실패하면 빌드 로그의 마지막 `RUN`을 보면 된다.
